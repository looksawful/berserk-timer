# Berserk Timer · Storybook

Браузерные референсы Python CLI/TUI без изменения таймера.

Истории: Предустановки, подготовка, отсчёт, пауза, завершение, команды, witness.

Запуск в каталоге preview: `npm ci`, `npm run storybook`. Сборка: `npm run storybook:build`.

Проверено 2026-11-07 на Titan (Node 24): `npm run storybook:build` → OK.

GitBook (не опубликован): https://app.gitbook.com/o/vNK58vV2S63vxervMh3G/sites/site_lj0eJ

Ограничение: сборка не подтверждает соответствие нативному UI. Деплой и runtime не меняются.
