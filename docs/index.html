Berserk Timer

CLI timer with witness mode and flexible duration input.

  • GitHub
  • Windows-first beta CLI timer
  • Flexible duration input and presets
  • Witness mode asks what you were doing after a session
  • Pause, resume, restart, mute, stop and zero-out controls
  • System and activity logs for later review

Install

  • Download ZIP
git clone https://github.com/looksawful/berserk-timer
cd berserk-timer
pip install -r requirements.txt

Usage

Start a timer with a duration, a fractional duration, a preset or silent mode.

python -m src.main 10
python -m src.main 1.5
python -m src.main -s
python -m src.main 25 --mute

p or Space    pause / resume
r             restart
m             mute
s or Esc      stop
z             zero out
