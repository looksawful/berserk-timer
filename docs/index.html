Berserk Timer

CLI timer with witness mode and flexible duration input.

  • GitHub
  • Windows-first beta CLI timer
  • Flexible duration input and presets
  • Witness mode asks what you accomplished after a session
  • Real keyboard controls: p, q, x, r, v, d, u, g, m, s, h, k
  • Audio settings menu for sound file, volume, mute and test preview

INSTRUCTIONS:
  • Set timer duration in minutes
  • Presets: -x (5min), -s (10min), -m (15min), -l (20min), -X (25min), -t (1min test)
  • Maximum duration: 3 hours
  • Set your goal for this session (if witness mode enabled, or skip)
  • Choose sound: --sound alert1.wav (or alert2/alert3/alert4)
  • Set volume in config.json (1-10 scale, default: 5)
  • During timer:
    - Press 'p' to pause/resume
    - Press 'q' to quit
    - Press 'x' to zero the timer
    - Press 'r' to restart
    - Press 'v' to view today's log
    - Press 'd' to delete today's log
    - Press 'u' to update duration
    - Press 'g' to set/change goal
    - Press 'm' to toggle silent mode
    - Press 's' to open audio settings (sound/volume)

Install

  • Download ZIP
~/berserk-timer
git clone https://github.com/looksawful/berserk-timer
cd berserk-timer
pip install -r requirements.txt

Usage

Start a timer with a duration, a fractional duration, a preset or silent mode.

~/berserk-timer
python -m src.main 10
python -m src.main 1.5
python -m src.main -s
python -m src.main 25 --mute
